# 📄 AI Resume Analyzer

An AI-powered Resume Analyzer built using **Python**, **Streamlit**, and **Ollama (Llama 3.2)**.

## 🚀 Features

- 📄 Upload Resume PDF
- 🤖 AI Resume Analysis
- ⭐ ATS Score
- 🎯 Resume vs Job Description Matching
- ✅ Skill Extraction
- ❌ Missing Skill Detection
- 💡 AI Suggestions
- 🎓 Education Extraction
- 🏆 Certification Detection
- 💼 Project & Experience Extraction
- 📊 Interactive Dashboard
- 📥 Download PDF Report

## 🛠 Tech Stack

- Python
- Streamlit
- Ollama
- Llama 3.2
- PyMuPDF
- pdfplumber
- Plotly
- ReportLab

## 📦 Installation

```bash
git clone https://github.com/Adithi105/AI-Resume-Analyzer.git
cd AI-Resume-Analyzer

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

streamlit run app.py
```
